# Rentozz Complete Frontend Demo

## Run
1. Install Node.js LTS.
2. Extract the ZIP and open this folder in VS Code.
3. Run `npm install`
4. Run `npm run dev`

## Included
Responsive landing page, browse/search/filter/sort, item details, local favorites, simulated booking requests, renter dashboard, partner dashboard, equipment listing form with photo previews, partner applications, admin application review, how-it-works, about, FAQ/help, contact form, responsive navigation and footer.

## Demo limitations
All data is stored in browser Local Storage. Bookings, approvals and messages are simulated. Photo selection is preview-only and does not upload to Supabase yet. Real authentication, permissions, bookings, payments and storage require backend integration. Never use real passwords or sensitive information in the demo. Equipment images are loaded from Unsplash and require internet access.
